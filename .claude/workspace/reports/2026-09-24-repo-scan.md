# Repo scan: Waste Land 2039 (2026-09-24)

## What it is
A **Unity 2022.3.62f1** 2D top-down zombie-survival / base-defense game using **URP 2D**. The player moves with WASD (legacy Input Manager, `Rigidbody2D` with gravity 0), shoots ranged weapons, defends a `MainBase`, collects and crafts items, and survives a day cycle of up to 30 days. Each day can trigger a `HordeEvent`.

## Size and layout
| Path | Size | Notes |

- **Not a git repository.** There is no version control at all.
- No existing Claude / AI-agent config (`IDEAS.md`, `.claude/`, `AGENTS.md`, `.cursor`, etc.). The only AI trace is Visual Studio's own `.vs/.../CopilotIndices`.

## Systems
- **Day / horde:** `GameTimer` (in `Assets/` root) holds `DayNum`, `MaxDays = 30`, and `dayHordeEvents` (day → `HordeEvent` SO). `HordeEventSpawner` spawns enemies. `HordeEvent` SO (menu *Game/Horde Event*) defines counts, intervals, enemy weights, stat multipliers, and rewards.
- **Combat:** `Enemy` (1,487 lines, the largest file), `EnemySpawner`, `RangedWeapon`, `WeaponManager`, `Bullet`, `IDamageable`, `MainBase` (repairable), `PlayerHealthRegeneration`.
- **Inventory / crafting:** `Item` / `CraftingRecipe` SOs, `Inventory`, `InventoryManager`, `InventoryUI`, drag-drop slots, tooltips, `CraftingManager`, `CraftingStation`, `CraftingUI`. Items include Bullet, Gun Powder, Iron Ingot, Copper Ingot, and Crude Fixer.
- **Meta / UI:** `GameManager`, `SceneController`, `PauseManager`, `MainMenuUI`, `PauseMenuUI`, `SurvivalManualUI` + `SurvivalManualData` SO, `TutorialGuideManager`, `DialogueSystem`, `IntroController` + `GifPlayer`, `TreasureChest`.
- **Art:** `Resources/ZombieWar` (sprite sheets and animations), `Resources/NormalEarth` and `InfectedEarth` (tile sets), `CP_V1.1.0_nyknck` tiles, `3DNPC_Characters` (asset-store pack with a demo scene).

## Issues noticed
1. ~~**Main menu scene can't load.**~~ **Fixed 2026-09-24.** Code and saved settings loaded `"MainMenu"`, but the file was `Main Menu.unity`. I renamed it (and its `.meta`, keeping the GUID) to `Assets/MainMenu.unity` with Unity closed. No code changes were needed.
2. ~~**Build Settings order.**~~ **Fixed 2026-09-24.** It is now `MainMenu` → `IntroScene` → `MainGame`. `SampleScene` (not referenced anywhere) was removed from the build list; the file itself is kept. Backups are in `backups/2026-09-24-main-menu-fix/`.
3. **Backup code is compiled.** `Assets/Scripts/WeaponSystem/Backup_HordeSpawner_20250920_121310/` contains `HordeSpawner.cs` and `HordeSpawner_Cleaned.cs`. They are compiled into the game, even though `GameManager` has its `HordeSpawner` usage commented out.
4. **Stale doc.** `HordeEvent_使用说明.txt` tells you to configure a `DayManager`, which no longer exists (only commented-out references remain). Horde setup is now on `GameTimer.dayHordeEvents`.
5. **Debug script clutter.** About 21 scripts under `InventorySystem/` are fixers, testers, debuggers, diagnostics, or demos (`InventorySystemFixer`, `TooltipSystemFixer`, `IngredientUIQuickFix`, `UIOverlapFixer`, `FontFixer`, …). The six fixers checked are not referenced by any scene (prefab references not checked).
6. **Loose files in the `Assets/` root:** `GameTimer.cs`, `HordeEventSpawner.cs`, `DialogueSystem.cs`, `RestartLogic.cs`, `Die.anim`, and `Day 2/3.asset` sit outside `Scripts/` and `Resources/`. `Assets/Editor/` and `Assets/Shaders/` are empty.
7. **No version control.** With 23k lines of code and no git, one bad edit can't be undone.
